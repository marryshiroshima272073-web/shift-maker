# 休み希望フォーム ver3.3 仕様書 (README.md)

LINEフロントエンドフレームワーク (LIFF) を利用した、薬局スタッフ専用の休み希望申請画面です。直感的でシームレスなUI/UXを提供し、モバイル端末での確実な操作性を重視して設計されています。

---

## 📋 概要
本システムは、スタッフがスマートフォン（LINEアプリ内）から自身の休暇・休み希望（公休、有休、振休、欠勤）をまとめてカレンダーから選択し、Google Apps Script (GAS) を経由してスプレッドシート等へワンタップで送信するためのフロントエンド画面です。

## ⚙️ 技術スタック
* **Frontend:** HTML5, CSS3 (Custom Properties, Flexbox, CSS Animation), JavaScript (Vanilla JS, ES6+)
* **SDK:** LIFF SDK v2 (`https://static.line-scdn.net/liff/edge/2/sdk.js`)
* **Backend (想定):** Google Apps Script (GAS) Web API

## 💡 バージョン 3.3 における重要な修正点・UX改善

### 1. iOS/Androidにおけるネイティブカレンダー起動の安定化
* **背景:** 従来のバージョンで発生していた「ボタンタップでカレンダー（`input[type="date"]`）が動かない、あるいは挙動が不安定になる」問題を根本解決しました。
* **アプローチ:** JavaScript側からの `showPicker()` や `.click()` などの無理なトリガー操作をすべて廃止。ボタン（`.btn-open-date`）と透明化したインプット（`.date-input-hidden`）をCSSの `position: absolute;` で完全に重ね合わせる手法を採用しました。
* **変更のメリット:** ユーザーがボタンエリアをタップした瞬間、確実にブラウザ・OS標準のネイティブ日付選択UIが100%起動します。

### 2. 重複選択および再選択時のバグフィックス
* **タップ時の値クリア:** カレンダーがタップされた瞬間に `touchstart` / `mousedown` イベントで `dateInput.value = '';` を実行し、前回値を明示的に消去。これにより「同じ日付を連続して選択しようとした際に `change` イベントが発火しない」不具合を解消しました。

## 📐 主要な機能と技術要件

### 1. 認証とプロフィール取得
* `liff.init()` 実行後、未ログイン状態であれば自動的に `liff.login()` を呼び出します。
* 取得したユーザー情報（`displayName`, `pictureUrl`）はヘッダー領域にリアルタイムで反映され、送信時のペイロード（`userId`）としても使用されます。
* ※ローカル環境などのブラウザテスト時は、キャッチブロックにより自動的に「テストユーザー」としてダミー挙動するようフォールバックが組み込まれています。

### 2. 下書き（Draft）機能とバリデーション
* カレンダーで日付が選択されると、下書きカード（`#draftCard`）がスムーズなスクロール（`scrollIntoView`）とともに展開されます。
* **バリデーション要件:**
    * **過去日の選択不可:** `input[type="date"]` に `sv-SE` フォーマット（`YYYY-MM-DD`）を用いて、当日以降のみ選択できるよう `min` 属性を動的に付与。
    * **重複チェック:** すでに下書きまたは確定リスト（`entries` Mapオブジェクト）に存在する日付は選択できず、エラーメッセージを表示。
    * **必須入力:** 「希望内容（公休・有休など）」が未選択の状態では決定できません（エラーを視覚的に通知）。

### 3. 送信履歴管理（同期型削除対応）
* 送信が成功すると、端末の `localStorage` にユーザー固有のキー（`kyuka_history_{userId}`）で履歴を保存します。
* **履歴の個別削除・一括削除:**
    * 履歴内の各レコードには一意の `historyId` が採番されます。
    * 画面側で履歴を消去する際、ローカルのデータを消すだけでなく、GAS側に対しても `action: 'delete'` または `action: 'deleteAll'` のペイロードを送信し、サーバー（スプレッドシート等）側と同期して削除処理を行います。
